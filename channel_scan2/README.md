visualstudio2022で作成
作成OS Windows11 64bit
行えること
TSパケットの取得と解析
文字デコードは日本国内での受信を想定した機能となっている
bondriverを利用したチャンネルスキャン、番組取得及びEPGの作成、予約録画
TVTest側に専用プラグインを置いた場合のみTVTestを利用した録画が可能となる
内部機能の録画はタイマー録画と1分毎のセルファイル録画をするタイムシフト録画の設定が可能となっている
作った機能テスト項目ごとにタブを分けているのでテストソフトを使ってる感覚で使えるようになってるはず
理論的には複数のチューナー設定を行うことが可能となっている
視聴する場合はtvtestなどの視聴アプリを利用すること
地上波のみテスト済み

TVTest制御用プラグインは以下のURLからTunerBridgePluginのコードをコンパイルしてTVTestに読み込ませて使ってほしい
https://github.com/rainoran/TunerBridgePlugin
